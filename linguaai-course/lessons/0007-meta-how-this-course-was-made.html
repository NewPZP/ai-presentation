元课程：这套教程是怎么被「教」出来的

预计 12 分钟 · 目标：理解 teach skill 的工作流——你现在读的这套课，本身就是 teach skill 的产物

跳出应用，看教程本身

前 5 课都在讲「怎么用 Agent 开发 LinguaAI」。这节课换个角度：你正在读的这套教程，就是用 teach skill 生成的。它同样遵循「先对齐、再产出」的方法论。

一句话记住

教一门课 = 先写使命和笔记，再按课号顺序产出可复用的 HTML。teach skill 不是「写一堆文章」，而是搭一个有骨架、有共享组件、有验收标准的教学工作区。

teach skill 的工作流

第一步：搜集资料，建立事实底座

不凭空写。先把所有一手素材摸清：

  • 36 个已关闭 issue（PRD + 主工单 + 增强/修复）
  • 50 次提交历史
  • 8 个工作日的全部会话摘要
  • 工程 README、项目记忆里的经验教训
  • .agents/skills/ 下每个 skill 的真实 SKILL.md

这些素材锚定进 NOTES.md，写课时只引用真实来源，不编造。

第二步：写三份「元文档」

在写任何一课前，先在仓库根目录建三个文件：

文件作用
MISSION.md课程使命 + 成功标准 + 约束 + 范围外
NOTES.md用户偏好、真实工具链/成本、skill 机制、课程地图、素材锚点
RESOURCES.md信任资源清单

这三份是「教学合同」：每课都要符合 MISSION 的约束、引用 NOTES 的事实、用 RESOURCES 的来源。用户随时可以改这三份来调整方向（比如你之前让我「减少技术篇幅」「按阶段组织」，就是改 NOTES 的课程地图）。

第三步：搭共享组件

不重复造轮子。先建两个共享文件，所有课复用：

  • assets/course.css — 统一视觉（卡片、提示框、表格、练习区、课程地图样式）
  • assets/quiz.js — 通用测验组件（LinguaQuiz('#quiz', [...])），每课末尾插几行 JS 就有即时反馈

这样每课只写内容，不操心样式和交互。

第四步：按课号顺序产出 HTML

每课一个 lessons/NNNN-主题.html，固定结构：

header（课号 + 标题 + 时长 + 目标）
↓
核心内容（分节，每节有一句话记忆点）
↓
callout / card（强调关键洞察）
↓
exercise（动手练习）
↓
quiz（即时反馈测验，3-4 题）
↓
footer（主资源 + 下一课预告 + 继续按钮）

用户说「继续第 N 课」，就按 NOTES 里的课程地图生成下一课，写完在浏览器打开。

第五步：用 learning-records 记录关键决策

每次有重要的方向调整（比如从 11 课改 7 课、读了真实 SKILL.md 修正命名），就写一条 learning-records/NNNN-标题.md，记清「事实 → 影响 → 修正」。这和 LinguaAI 的项目记忆是同一个思路：把决策固化，后续不重踩。

这套工作流的设计哲学

  1. 先骨架后血肉——MISSION/NOTES/课程地图先定，再写内容。改方向时改骨架，不改每课。
  2. 共享组件优先——css 和 quiz.js 只写一次，每课复用。
  3. 事实锚定——所有 skill 讲解以真实 SKILL.md 为准，不复述用户口述（所以才会发现 to-tickets 是复数、grill-me 调 grilling）。
  4. 逐课交付 + 即时反馈——一课一课来，每课末尾有测验，用户随时可以喊停或调整。
  5. 教学产物不进 git——MISSION/NOTES/lessons/assets 在用户确认前都是工作区文件，不污染工程仓库。

你可以怎么复用这套方法

teach skill 的流程不限于教「用 Agent 开发」。任何你想沉淀成教程的主题——你熟悉的框架、你踩过的坑、你团队的工作流——都可以套这个模板：

  1. 先写 MISSION（教什么、学成什么样、不教什么）
  2. 再写 NOTES（素材锚点、课程地图、你的偏好）
  3. 搭共享组件（哪怕只是一个 css 文件）
  4. 按课号产出，每课有练习和测验
动手练习
  1. 打开本仓库的 MISSION.md 和 NOTES.md，对比它们的结构：MISSION 管「为什么和边界」，NOTES 管「事实和地图」。想想为什么要分成两个文件而不是一个。
  2. 看 assets/quiz.js 和任意一课末尾的 LinguaQuiz(...) 调用，体会共享组件怎么让每课只写内容。
  3. 思考题：如果你要把这套教程教给别人，你会怎么改写 MISSION 的「Success looks like」？

课后

主资源：本仓库的 MISSION.md、NOTES.md、assets/、lessons/——你正在读的就是它们的产物。
