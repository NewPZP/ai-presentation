# 学习路径里程碑：Agent 已具备 Web 服务形态

用户在 2026-07-28 完成到第 6 课，Agent 已具备以下完整能力：

- 工具调用（get_weather、calculate，可扩展）
- Agent 循环（while True + tool_calls 处理）
- 系统提示（行为规则、人格设定）
- 短期记忆（messages 列表跨轮保留）
- 长期记忆（memory.json 持久化，跨会话）
- 封装成 WeatherAgent 类（多用户、可测试）
- 错误处理（LLM 指数退避重试 + 工具失败自我修复）
- Web 服务化（FastAPI + /chat 接口 + 多用户隔离）

这意味着用户已经能交付一个最小可用的 Agent 产品原型——能被别人通过网络调用，能记住不同用户的历史。

下一步的关键不再是「让 Agent 能干更多事」，而是：
1. **评测**（第 7 课）：怎么知道 Agent 好不好用，能量化吗
2. **生产化**：Redis 存储、认证、限流、部署上云
3. **进阶能力**：流式输出、RAG、多 Agent 委托

注意用户已完成 6 课都没有卡壳，节奏可以适当加快，但仍要保证每课有可运行产出。
