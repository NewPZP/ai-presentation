# 起点画像与教学方向

用户在 2026-07-28 首次对话中确立了以下起点，决定后续课程设计：

- **背景**：AI 新手（会用 ChatGPT，没调过 LLM API，没碰过 Agent），会一点 Python/JS 编程。
- **目标**：做个人项目/创业，要能从零做出一个真能干活的 Agent 并部署上线。
- **口径**：用户说的「AI Agent 2.0」理解为「Agent 工程实战」，不绑定某个特定框架。

这意味着第一课不能假设用户懂 Prompt Engineering 或 tool calling，必须从「LLM 一次性调用 vs Agent 循环」这个最小心智模型切入，并立刻给一段能跑的代码作为锚点。之后按「最小 Agent → 加工具 → 加记忆 → 加评测 → 部署」的路径推进，优先用原生 SDK 而非重型框架，让概念清晰。
