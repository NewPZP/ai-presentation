# 评测（Evals）术语补充 **Evals（评测）**: 给 Agent 一组固定输入，用预先定义的标准给输出打分的结构化方法。是 Agent 工程和「调 prompt 玄学」的分水岭。 _避免_: 测试（太宽泛） **Rubric（评分标准）**: 对单个评测用例定义「什么样的回答算对」的清单。通常包含必须包含的信息、禁止出现的内容、格式要求等。 **LLM-as-a-Judge（LLM 当裁判）**: 用另一个 LLM 按 rubric 给被测 Agent 的回答打分。工业界标准做法，快、便宜、可重复，但有偏差，需要人工抽检校准。 **Baseline（基准）**: 固定评测用例的初始得分。后续每次改动（改 prompt、换模型、加工具）都和 baseline 比，量化改动效果。 **数据泄漏（Data Leakage）**: 评测用例出现在了 Agent 的训练材料或系统提示里，导致评测结果虚高、不代表真实表现。
