# 生产化关键术语补充 **状态外置（Stateless Service）**: 把服务进程设计成无状态的--所有状态（用户记忆、会话数据）存到外部存储（Redis/DB），进程本身不持有。这是云原生时代的基本原则，带来：可水平扩展、可重启不丢数据、可灰度发布。 _避免_: 无状态服务（太宽泛） **TTL（Time To Live）**: 数据的过期时间。Redis 里给 key 设 TTL，到期自动删除。用于自动清理冷用户数据，避免无限堆积。 **SSE（Server-Sent Events）**: HTTP 长连接的一种形式，服务端持续推送事件给客户端，浏览器原生支持。比 WebSocket 简单，适合 LLM 流式输出这种「服务端 -> 客户端」单向场景。 **滑动窗口限流**: 限流算法的一种：记录最近 N 秒内的所有请求时间戳，超过阈值就拒绝。比固定窗口更平滑，避免窗口边界处的突发流量。 **12 Factor App**: 云原生时代的应用设计原则，共 12 条。核心包括：配置通过环境变量注入、无状态进程、日志作为事件流等。本课的「环境变量分离配置」就是其中一条。
