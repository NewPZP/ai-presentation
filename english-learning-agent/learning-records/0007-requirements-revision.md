# 0007 — 需求修订：从线性阶段到功能模块

## 变更内容
用户要求将项目从「线性 6 阶段教学流程」改为「6 个功能模块（推荐路径不强制）」。

### 原 6 阶段（线性）
词汇预习 → 朗读 → 重点词汇 → 句子讲解 → 练习 → 检验

### 新 6 功能模块（推荐路径，不强制）
① 预习单词 → ② 播客（泛听）→ ③ 听力训练（精听）→ ④ 单词测验 → ⑤ 综合测验 → ⑥ 学习进度

## 用户确认的关键决策
1. **功能组织**：推荐路径（有顺序但不强制，未推荐也能点）
2. **播客音频**：TTS 生成（火山方舟豆包语音合成）
3. **单词卡片交互**：翻转卡片 + 间隔重复结合。不认识时翻转看释义，认识则移出队列
4. **听力 vs 播客**：播客=整篇播放+字幕（泛听），听力=逐句听写（精听）

## 新增功能（原方案没有的）
- **TTS 语音合成**：单词发音 + 文章音频，火山方舟提供
- **播客播放器**：整篇播放 + 字幕同步高亮，技术最复杂
- **听力训练**：逐句听写 + 对比纠错
- **学习进度面板**：各功能完成度 + 掌握统计

## 架构调整
| 变化点 | 原来 | 现在 |
|--------|------|------|
| 路由 | `/articles/[id]/[phase]` | `/articles/[id]/[feature]` |
| 状态 | 阶段状态机（线性） | 6 功能独立完成状态 |
| 学习页 | 通用聊天页按 phase 切提示 | 6 个独立功能页各有专属 UI |
| TTS | 无 | 新增语音合成 API |

## 课程计划调整
- 第 1-6 课保留（基础设施 + 词汇提取）
- 第 6 课卡片展示将在第 7 课改造为轮播+翻转+间隔重复
- 原第 7-12 课作废，重新规划第 7-14 课

### 新课程计划
7. 词汇卡片轮播：翻转 + 间隔重复 + 发音占位
8. TTS 语音合成：火山方舟 TTS API
9. 播客播放器：整篇播放 + 字幕同步
10. 听力训练：逐句听写
11. 单词测验：选择题 + 拼写
12. 综合测验：阅读理解 + 词汇应用
13. 学习进度面板
14. 状态管理与部署

## 非显然决策
- **推荐路径但不强制**：学习需要灵活性，强制顺序会挫伤积极性。推荐路径用视觉引导（高亮当前推荐），但不锁功能
- **TTS 生成后缓存 localStorage**：TTS 有成本和延迟，整篇文章音频不能每次实时生成。首次生成后缓存
- **听力训练复用播客音频**：播客 TTS 生成整篇音频后，听力训练按句切片复用，不重复生成
- **单词测验基于预习单词**：只考学过的词，数据流是 词汇提取 → 单词测验
- **发音占位策略**：第 7 课卡片轮播先放发音按钮占位，第 8 课 TTS 实现后接上。避免第 7 课被 TTS 阻塞
