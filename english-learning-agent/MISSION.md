# Mission: 构建一个人机协作学习英文文章的 AI Agent 应用

## Why
用户已完成 14 课 AI Agent 工程课程，掌握了 Agent 核心概念（工具调用、记忆、流式输出、RAG、多 Agent、部署）。现在要把这些能力落地成一个**自己真正会用的产品**——一个通过多种交互方式学习英文文章的 Agent。

应用的核心价值：不是让 AI 直接翻译或总结文章，而是提供**6 个功能模块**覆盖听、读、练、测的完整学习闭环，AI 负责内容生成（提取生词、出题、评分），用户主动练习。

## 产品功能（2026-08-01 需求修订）

### 6 个功能模块（推荐路径，不强制）

```
① 预习单词 → ② 播客（泛听）→ ③ 听力训练（精听）→ ④ 单词测验 → ⑤ 综合测验 → ⑥ 学习进度
```

文章卡片上 6 个按钮按推荐顺序排列。推荐项高亮，未推荐的也能点（不锁），完成的显示 ✓。

#### ① 预习单词 · 翻转卡片 + 间隔重复
- 卡片正面：单词 + 音标 + 🔊发音按钮
- 底部「认识」/「不认识」按钮
- 不认识 → 翻转看释义+例句 → 重新排到队列尾部（间隔重复）
- 认识 → 移出队列
- 全部认识后完成
- 数据：复用 generateObject 词汇提取
- 依赖：发音需要 TTS（第 8 课实现，先放占位）

#### ② 播客 · 整篇播放 + 字幕同步
- 播放器：▶/⏸、进度条、倍速（0.75x/1x/1.25x/1.5x）
- 字幕区：文章按句分段，当前句高亮，点击句子跳转播放
- 音频：火山方舟 TTS 生成，长文章分段生成，缓存到 localStorage
- 技术难点：字幕与音频时间戳同步

#### ③ 听力训练 · 逐句精听
- 文章按句拆分，逐句训练
- 每句：播放音频 → 用户听写输入 → 对比原文 → 标红差异
- 可选：跟读模式（播放→录音→回放对比）
- 与播客区别：播客是整篇自由听（泛听），听力是逐句听写做题（精听）
- 音频：复用播客 TTS 音频，按句切片

#### ④ 单词测验 · 选择题 + 拼写
- 题目基于预习单词生成（只考学过的词）
- 题型：看释义选单词 / 看单词选释义 / 听音拼写
- 即时反馈对错 + 完成后总分 + 错题列表
- 数据：generateObject 生成题目

#### ⑤ 综合测验 · 阅读理解 + 词汇应用
- 文章理解题（主旨/细节/推理）
- 词汇应用题（填空/造句）
- 翻译题（英译中/中译英）
- 评分 + 分项反馈（阅读/词汇/翻译各得分）
- 与单词测验区别：单词测验只考词汇，综合测验考整体理解+应用

#### ⑥ 学习进度 · 数据面板
- 6 个功能完成度（进度条/百分比/状态）
- 单词掌握统计：认识 X / 不认识 Y
- 测验成绩：单词测验 + 综合测验
- 学习时长（可选）

## Success looks like
- 能独立用 Next.js + Vercel AI SDK 搭建一个全栈 AI 应用
- 应用能导入 PDF/TXT 并提取文本
- 6 个功能模块完整可用，覆盖听读练测闭环
- TTS 语音合成集成（单词发音 + 文章音频）
- 学习状态能持久化（记住学了哪些词、各功能完成度）
- 应用能部署上线，自己日常可用

## 技术栈（用户已确认）
- **Next.js（App Router）+ TypeScript**：全栈框架
- **Vercel AI SDK**：`streamText` + `generateObject` + `useChat`，统一 LLM 调用与结构化输出
- **火山方舟（Volcengine Ark）/ 豆包模型**：LLM + TTS 语音合成。OpenAI 兼容接口，用 `@ai-sdk/openai-compatible` 接入。generateObject 必须用 `mode: 'tool'`（火山方舟对 JSON 模式支持不完整）
- **Tailwind CSS**：UI 样式基础
- **shadcn/ui**：组件库
- **pdfjs-dist**：PDF 文本提取
- **Vercel**：部署

## 架构
- **路由**：`/articles/[id]/[feature]`，feature = vocab | podcast | listening | vocab-quiz | final-quiz | progress
- **状态**：6 个功能独立完成状态（notStarted/inProgress/completed），推荐路径但不强制
- **TTS**：新增语音合成 API 路由，播客和单词发音共用
- **数据流**：词汇提取 → 单词测验（基于提取的词出题）；播客 TTS → 听力训练（复用音频切片）

## Constraints
- 用户有 Python/JS 基础，但 **Next.js / React / TypeScript 是新领域**
- 中文教学，代码注释用中文
- 优先 Vercel AI SDK 官方文档 + 一手权威来源
- 每课要有可运行的产出
- shadcn/ui 组件库复用

## Out of scope
- 用户系统 / 多租户 / 权限管理
- 移动端原生 App
- 语音识别评分（跟读模式可选，不做评分）
- 课程内容生产（文章素材由用户自己导入）

## 与前一课程的关系

本课程是**项目实战**：换技术栈（Next.js + AI SDK），聚焦一个具体产品，把 Agent 思维落地。
