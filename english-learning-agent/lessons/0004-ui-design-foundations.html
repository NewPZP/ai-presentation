UI 设计基础：配色、排版、组件库

设计系统 + shadcn/ui + 消息气泡/卡片组件 · 约 30 分钟 · 产出：统一的聊天界面，后续课程复用

本课目标

前三课我们专注跑通功能，UI 是「能用就行」的水平——按钮、进度条、消息列表都是手写 Tailwind 类，风格散乱。今天我们要打 UI 地基：定一套设计系统（配色、排版、间距），引入 shadcn/ui 组件库，把聊天界面重构成统一风格的可复用组件。

这课不做新功能，但后面所有课的 UI 都建立在这套基础上。磨刀不误砍柴工。

你将学会三件事：

  • 什么是设计系统，为什么不能靠临时想颜色
  • 用 shadcn/ui 安装和定制组件（Button、Card、ScrollArea、Avatar）
  • 把聊天界面拆成可复用组件（MessageBubble、PhaseProgress、FileImporter）

为什么需要设计系统？

前三课你可能已经感觉到：每次写 UI 都在临时拍板——这个按钮用 bg-teal-600 还是 bg-blue-500？圆角 rounded 还是 rounded-lg？字号 text-sm 还是 text-base？结果是界面风格不统一，改一处要全局搜替换。

设计系统就是把这些决策提前定好、集中管理：

决策没有设计系统有设计系统
主色每个按钮各自写颜色类统一用 primary 语义令牌，改一处全局生效
圆角rounded / rounded-lg / rounded-md 混用统一用 --radius 变量
间距拍脑袋写 p-3 / p-4 / p-6遵循 4px 网格，语义化命名
按钮每个地方手写 <button> + Tailwind 类用 <Button> 组件，variant 统一

核心原则：UI 不该靠记忆和临场发挥，而该靠令牌（token）和组件。令牌是「这个颜色叫 primary」的语义命名，组件是「按钮长这样」的封装。两者配合，改设计 = 改令牌/组件，而不是全局搜替换。

第一步：初始化 shadcn/ui

注意：shadcn 的 init 选项会随版本变化。如果你看到的提示和本课写的不一样，以官方文档为准：ui.shadcn.com/docs/installation/next。核心流程不变——运行 init，它会自动配置好 components/ui/ 目录、lib/utils.ts、CSS 变量、依赖。如果交互提示让你选，按下面的说明选；如果没提示直接跑完了，跳到「安装组件」即可。

在项目根目录运行：

pnpm dlx shadcn@latest init

这个命令会自动做几件事（无需手动干预）：

  • 创建 components/ui/ 目录（放组件源码）
  • 创建 lib/utils.ts（含 cn() 函数，合并 Tailwind 类名）
  • 在 app/globals.css 里写入 CSS 变量（配色令牌）
  • 安装依赖：tailwind-merge、clsx、class-variance-authority
  • 更新 components.json（shadcn 的配置文件，记录路径和风格）

如果你运行时遇到交互式提示（老版本或某些环境），按这个选即可——选错也不怕，都能在 components.json 和 globals.css 里改：

提示（如出现）选择说明
Which styleNew York更紧凑现代（另一个 Default 更圆润）
Base colorSlate灰蓝色调，干净（后面我们会改成青绿主色）
CSS variables / CSS variables for colorsYes用 CSS 变量，方便定制主题

新版 shadcn 推荐用 shadcn/create 可视化预设（在网页上选风格生成命令），但本课直接用 CLI 就行，结果一样。

安装本课要用的组件

pnpm dlx shadcn@latest add button card scroll-area avatar separator

每个组件的作用：

组件用在哪
Button替换所有手写 <button>，统一按钮风格
Card文件导入区、词汇卡片、练习题卡片
ScrollArea消息列表滚动区域（比原生 overflow 好控制）
Avatar消息头像（区分用户和 AI）
Separator分区线

shadcn/ui 和传统组件库（Ant Design、MUI）的本质区别：传统组件库是 npm install 一个包，组件代码在 node_modules 里，你改不了。shadcn/ui 是把组件源码拷贝到你项目里（components/ui/），你想怎么改就怎么改。它是「你的代码」，不是「依赖的代码」。

第二步：理解设计令牌

打开 app/globals.css，shadcn/ui 已经写入了 CSS 变量。关键部分：

:root {
  --background: 0 0% 100%;        /* 背景色：白 */
  --foreground: 222 47% 11%;      /* 文字色：深灰蓝 */
  --primary: 222 47% 11%;         /* 主色：深灰蓝 */
  --primary-foreground: 210 40% 98%;
  --muted: 210 40% 96%;           /* 次要背景：浅灰 */
  --muted-foreground: 215 16% 47%; /* 次要文字：中灰 */
  --border: 214 32% 91%;          /* 边框色 */
  --radius: 0.5rem;               /* 圆角 */
}

注意这些值用的是 HSL 三个数（色相 饱和度 亮度），不是 #hex。这是为了方便用 Tailwind 的透明度修饰符——bg-primary/50 会自动变成 hsl(var(--primary) / 0.5)。

定制主色：换成青绿色

前三课我们一直用 teal-600，现在把它纳入设计系统。把 --primary 改成青绿色：

:root {
  --background: 0 0% 100%;
  --foreground: 222 47% 11%;

  /* 主色：青绿（对应 Tailwind teal-600）*/
  --primary: 173 80% 40%;
  --primary-foreground: 0 0% 100%;

  --muted: 210 40% 96%;
  --muted-foreground: 215 16% 47%;
  --border: 214 32% 91%;
  --radius: 0.5rem;
}

改完后，所有用 bg-primary 的地方（Button、Card 等）自动变成青绿色。这就是令牌的威力——改一处，全局生效。

3.1 消息气泡组件

新建 components/message-bubble.tsx：

// components/message-bubble.tsx
import { UIMessage } from "ai";
import { cn } from "@/lib/utils";
import { Avatar, AvatarFallback } from "@/components/ui/avatar";

export function MessageBubble({ message }: { message: UIMessage }) {
  const isUser = message.role === "user";

  return (
    <div className={cn(
      "flex gap-3 mb-4",
      isUser && "flex-row-reverse"
    )}>
      {/* 头像 */}
      <Avatar className="w-8 h-8 shrink-0">
        <AvatarFallback className={cn(
          "text-xs",
          isUser ? "bg-primary text-primary-foreground" : "bg-muted"
        )}>
          {isUser ? "我" : "AI"}
        </AvatarFallback>
      </Avatar>

      {/* 气泡 */}
      <div className={cn(
        "rounded-lg px-4 py-2 max-w-[80%]",
        isUser
          ? "bg-primary text-primary-foreground"
          : "bg-muted text-foreground"
      )}>
        {message.parts.map((part, i) =>
          part.type === "text" ? (
            <p key={i} className="whitespace-pre-wrap">{part.text}</p>
          ) : null
        )}
      </div>
    </div>
  );
}

关键点：

  1. cn() 函数 — shadcn/ui 提供的工具，合并 Tailwind 类名并处理冲突。条件类名用 cn("base", isUser && "flex-row-reverse") 写，比模板字符串干净。
  2. 用户消息靠右、AI 消息靠左 — flex-row-reverse 让用户消息整体翻转（头像到右边）。这是聊天的视觉约定。
  3. max-w-[80%] — 气泡最多占 80% 宽度，避免长消息占满整行，保持对话感。
  4. 组件只管渲染 — 不含任何状态、不调 API。纯展示组件，接收 message 就能渲染。这种组件最容易复用和测试。

3.2 阶段进度组件

新建 components/phase-progress.tsx：

// components/phase-progress.tsx
import { Phase, PHASE_INFO, PHASE_ORDER, getNextPhase, getPhaseIndex, TOTAL_PHASES } from "@/lib/learning-phases";
import { Button } from "@/components/ui/button";
import { cn } from "@/lib/utils";

interface Props {
  currentPhase: Phase;
  onNextPhase: () => void;
}

export function PhaseProgress({ currentPhase, onNextPhase }: Props) {
  const next = getNextPhase(currentPhase);

  return (
    <div className="mb-4 p-4 border rounded-lg">
      {/* 阶段标题 + 下一步按钮 */}
      <div className="flex items-center justify-between mb-2">
        <span className="font-medium">
          第 {getPhaseIndex(currentPhase)}/{TOTAL_PHASES} 阶段：
          {PHASE_INFO[currentPhase].label}
        </span>
        {next && (
          <Button variant="secondary" size="sm" onClick={onNextPhase}>
            进入「{PHASE_INFO[next].label}」→
          </Button>
        )}
      </div>

      <p className="text-sm text-muted-foreground mb-2">
        {PHASE_INFO[currentPhase].description}
      </p>

      {/* 进度条 */}
      <div className="flex gap-1">
        {PHASE_ORDER.map((p) => (
          <div
            key={p}
            className={cn(
              "flex-1 h-2 rounded-full transition-colors",
              p === currentPhase && "bg-primary",
              PHASE_ORDER.indexOf(p) < PHASE_ORDER.indexOf(currentPhase) && "bg-primary/40",
              PHASE_ORDER.indexOf(p) > PHASE_ORDER.indexOf(currentPhase) && "bg-border"
            )}
          />
        ))}
      </div>
    </div>
  );
}

关键点：

  1. variant="secondary" size="sm" — shadcn/ui Button 的变体系统。secondary 是次要按钮样式（浅色背景），sm 是小尺寸。不用手写颜色类，语义清晰。
  2. bg-primary/40 — 已完成阶段用主色 40% 透明度。靠 CSS 变量 + Tailwind 透明度修饰符实现，不用单独定义颜色。
  3. transition-colors — 切换阶段时进度条颜色平滑过渡，小细节提升质感。

3.3 文件导入组件

新建 components/file-importer.tsx：

// components/file-importer.tsx
import { useRef, useState } from "react";
import { Button } from "@/components/ui/button";
import { Card } from "@/components/ui/card";
import { Upload, FileText, Loader2 } from "lucide-react";

interface Props {
  onFileUploaded: (text: string, fileName: string) => void;
}

export function FileImporter({ onFileUploaded }: Props) {
  const [uploading, setUploading] = useState(false);
  const [error, setError] = useState("");
  const [fileName, setFileName] = useState("");
  const [wordCount, setWordCount] = useState(0);
  const fileInputRef = useRef<HTMLInputElement>(null);

  async function handleFileChange(e: React.ChangeEvent<HTMLInputElement>) {
    const file = e.target.files?.[0];
    if (!file) return;

    setUploading(true);
    setError("");
    try {
      const formData = new FormData();
      formData.append("file", file);
      const res = await fetch("/api/upload", { method: "POST", body: formData });
      const data = await res.json();
      if (!res.ok) throw new Error(data.error || "上传失败");

      onFileUploaded(data.text, data.fileName);
      setFileName(data.fileName);
      setWordCount(data.text.split(/\s+/).length);
    } catch (err) {
      setError(err instanceof Error ? err.message : "上传失败");
    } finally {
      setUploading(false);
    }
  }

  return (
    <Card className="mb-4 p-4">
      <input
        type="file"
        accept=".pdf,.txt,.md"
        onChange={handleFileChange}
        ref={fileInputRef}
        className="hidden"
      />

      <div className="flex items-center gap-3">
        <Button
          variant="default"
          onClick={() => fileInputRef.current?.click()}
          disabled={uploading}
        >
          {uploading ? (
            <><Loader2 className="w-4 h-4 mr-2 animate-spin" />提取中...</>
          ) : (
            <><Upload className="w-4 h-4 mr-2" />导入文章</>
          )}
        </Button>

        {fileName && (
          <span className="flex items-center gap-1 text-sm text-muted-foreground">
            <FileText className="w-4 h-4" />
            {fileName}（{wordCount} 词）
          </span>
        )}
      </div>

      {error && <p className="mt-2 text-sm text-red-600">{error}</p>}
    </Card>
  );
}

关键点：

  1. lucide-react 图标 — shadcn/ui 默认用 Lucide 图标库。Upload（上传）、FileText（文件）、Loader2（加载旋转）让 UI 更直观。先装：pnpm add lucide-react。
  2. animate-spin — Tailwind 内置旋转动画，Loader2 图标配它就是加载转圈。
  3. 状态提升 — 组件不持有 articleText，上传成功后调 onFileUploaded(text, fileName) 把数据交给父组件。这叫受控组件——数据在父组件，子组件只管 UI 和触发。对应 React 的「状态提升」原则。
  4. <Card> 替代手写 div border rounded-lg bg-gray-50 — 风格统一，自带阴影和圆角。

第四步：用组件重写主页面

现在 app/page.tsx 可以瘦身成这样：

// app/page.tsx
'use client';

import { useChat } from "@ai-sdk/react";
import { useState } from "react";
import { Phase } from "@/lib/learning-phases";
import { FileImporter } from "@/components/file-importer";
import { PhaseProgress } from "@/components/phase-progress";
import { MessageBubble } from "@/components/message-bubble";
import { Button } from "@/components/ui/button";
import { ScrollArea } from "@/components/ui/scroll-area";
import { getNextPhase } from "@/lib/learning-phases";

export default function Chat() {
  const { messages, sendMessage, status } = useChat();
  const [input, setInput] = useState("");
  const [articleText, setArticleText] = useState("");
  const [currentPhase, setCurrentPhase] = useState<Phase>("preview");

  const canChat = articleText && status === "ready";
  const nextPhase = getNextPhase(currentPhase);

  return (
    <div className="flex flex-col h-screen max-w-2xl mx-auto px-4 py-6">
      {/* 文件导入 */}
      <FileImporter
        onFileUploaded={(text, name) => {
          setArticleText(text);
          setCurrentPhase("preview");
        }}
      />

      {/* 阶段进度 */}
      {articleText && (
        <PhaseProgress
          currentPhase={currentPhase}
          onNextPhase={() => nextPhase && setCurrentPhase(nextPhase)}
        />
      )}

      {/* 消息列表 */}
      <ScrollArea className="flex-1 pr-4">
        {messages.map((message) => (
          <MessageBubble key={message.id} message={message} />
        ))}
      </ScrollArea>

      {/* 输入框 */}
      <form
        onSubmit={(e) => {
          e.preventDefault();
          if (!input.trim() || !canChat) return;
          sendMessage(
            { text: input },
            { body: { articleText, phase: currentPhase } }
          );
          setInput("");
        }}
        className="mt-4 flex gap-2"
      >
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          placeholder={articleText ? "说点什么..." : "先导入一篇文章吧"}
          disabled={!canChat}
          className="flex-1 rounded-md border border-border bg-background px-3 py-2"
        />
        <Button type="submit" disabled={!canChat}>发送</Button>
      </form>
    </div>
  );
}

小测验

设计系统的核心

为什么改 --primary 一个 CSS 变量，所有按钮和进度条都变色？

  • 因为 CSS 变量是全局的，自动覆盖所有元素
  • 因为组件引用令牌（primary）而非具体颜色，令牌一改全部跟着变
  • 因为 shadcn/ui 有魔法，自动同步颜色
  • 因为 Tailwind 会重新编译所有类名

shadcn/ui 的特点

shadcn/ui 和 Ant Design 等传统组件库的本质区别是什么？

  • shadcn/ui 更轻量，功能更少
  • shadcn/ui 只能用 Tailwind，传统库不限
  • shadcn/ui 把组件源码拷进你的项目，你完全可控
  • shadcn/ui 免费传统库收费

组件设计

FileImporter 组件不持有 articleText，而是调 onFileUploaded 回调——这是什么模式？

  • 受控组件 / 状态提升：数据在父组件，子组件只管 UI
  • 全局状态管理：用 Context 共享数据
  • 服务端组件：数据在服务端获取
  • 不可变数据：组件不存任何状态
