# Mission: 用 2–3 个月拿下 RAG 方向的面试（应用岗 + 算法岗）

## Why
用户正在准备 AI 方向的工作面试，RAG 是「大模型应用开发」和「大模型算法」两类岗位的公共必考区。他目前的 RAG 底子只有「AI Agent 2.0」第 11 课的朴素 demo——切分、向量化、余弦检索——而面试真正要考的是从「能跑起来」到「能量化、能选型、能讲清取舍」的那一整段距离。他两类岗位都投，按轮次分别准备：应用岗考工程落地与架构选型，算法岗考 embedding 与重排的原理和训练。

## Success looks like
- 对着白板 15 分钟设计出一个企业知识库问答系统，并说清每处技术选择的理由和代价
- 讲清向量检索、BM25、混合检索、cross-encoder 重排、HNSW 与 IVF-PQ 的原理与适用边界，答得出「为什么不是另一个」
- 解释 embedding 的训练目标（对比学习、难负样本、in-batch negatives）与 reranker 在建模上的本质差异
- 手撕得出 RRF 融合、Recall@k / MRR / nDCG 指标，以及一个能跑的检索评测脚本
- **手上有一个真实语料跑出来的 RAG 项目**：能讲出改了什么组件、指标动了多少、哪次尝试失败了、为什么
- 接得住高频追问：召回差怎么办、答不准怎么办、长文档怎么办、成本怎么降、怎么证明改好了

## Constraints
- 起点：会朴素 RAG demo，会 Python；**没有做过真实语料的 RAG 项目**（这是当前最大缺口）
- 时间：2–3 个月，可以系统推进，不是临考突击
- 中文教学，代码注释用中文
- 每节课标注考点归属：`应用岗` / `算法岗` / `both`，便于按面试轮次挑重点
- 资源优先一手：原始论文、官方文档、官方工程博客
- 私人学习工作区，暂不发布到主页作品墙

## Out of scope
- 通用 LLM 预训练原理与微调全流程（只在理解 RAG 必需时触及）
- Agent 循环、工具调用、多 Agent 编排（已在「AI Agent 2.0」覆盖）
- 图像 / 音视频等非文本模态的检索
- 产品经理向的 RAG 科普与厂商竞品盘点
