# 起点：朴素 RAG 基础，以及一个必须先补的缺口

用户在 2026-09-23 确立了起点：已完成「AI Agent 2.0」全部 14 课，RAG 只做过第 11 课的朴素三件套 demo（chunking / embedding / 余弦相似度检索），**没有在真实语料上跑过 RAG**。目标是用 2–3 个月准备「大模型应用开发 / 大模型应用工程师」与「大模型算法工程师」两类岗位面试，五个环节（概念八股、系统设计、手撕代码、项目深挖、论文与算法原理）全都要练。

**Implications**：起点不必重复「什么是 RAG」，可以直接从「面试官要的标准答案结构」切入，把朴素管线升级成带失分点的作战地图。但勾选的「项目深挖」与现状直接冲突——**没有真实项目就没有可讲的素材**，靠背诵他人项目经不起追问。因此课程中段必须插入一个真实语料的 RAG 项目，并刻意制造可讲的取舍、失败与指标变化。此外所有知识点都要标注岗位归属，否则用户无法按面试轮次取舍。
