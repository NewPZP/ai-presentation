必备插件速查表

社区实测前 10 名 · 安装命令 + 适用人群 · 打印友好

数据截至 2026-09，DSH 生态变化很快，安装前请在 dsh-market 里搜最新版本。

三步走起步策略

不要一口气装十个。先装「市场 + 视觉」，再装一个界面插件，最后按需补搜索和记忆。

阶段插件目的
第一步dsh-market + modlens生态入口 + 视觉能力
第二步dsh-web-ui 或 DSH-better-sidebar（二选一）界面升级
第三步按需：搜索 / 记忆 / 费用 / 知识库补齐高频痛点

插件清单

#插件作用安装命令
1 dsh-market
生态入口		 插件市场。装了它可以在设置里一键搜索、安装社区插件和主题，还能备份还原配置。 dsh plugin --profile web add dshmarket
2 modlens
视觉扩展		 给纯文本模型装上眼睛。粘贴图片自动 OCR + 版面分析。表格、论文、报错截图秒转文字。 npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modlens@3.25.2
3 dsh-web-ui
界面全家桶 ⭐6.4k		 任务看板、Git 图谱、Token 实时统计、桌面宠物。把极简聊天框升级成全功能控制台。 dsh plugin --profile web add @linxin666/dsh-web-all@latest
4 DSH-better-sidebar
侧边工作台 ⭐3.1k		 VS Code 风格侧边栏，内置文件树、真实终端、子代理状态监控。和 #3 二选一或同装。 dsh plugin --profile web add dsh-better-sidebar@latest
若失败：cd ~/.dsh/profiles/web && pnpm approve-builds --all 后重试
5 dsh-at-file
快速引用		 输入框打 @ 模糊搜索本地文件，回车引用进上下文。不用再复制粘贴。 dsh plugin --profile web add https://github.com/omdsh-dev/dsh-at-file/archive/refs/tags/v0.6.8.tar.gz
6 deepseek-harness-desktop
桌面客户端		 官方 Web UI 的桌面封装。免配置 Node.js，系统托盘常驻，点开就用。 从仓库下载安装包
7 dsh-web-search-pro
多源搜索		 聚合 DeepSeek、Bing、Exa 多引擎，支持小红书/知乎/B 站定向爬取，结果本地缓存。 dsh-market 搜索安装
8 OpenViking
跨会话记忆		 自进化上下文数据库，把碎片对话变成长期记忆和知识 RAG。上周聊的项目背景这周还记得。 dsh-market 搜索 dsh-openviking
9 dsh-cost-meter
费用看板		 实时统计会话花费和当日预算，峰谷电价切换前自动提醒。涨价后必备。 dsh-market 搜索安装
10 dsh-session-library
知识库精读		 本地文档混合检索 + 长文精读。把 PDF 自动拆成主张和证据链，读论文神器。 dsh-market 搜索 session library 或 dsh-okf

插件安装通用命令

# 基本格式
dsh plugin --profile web add <包名或 URL>

# 常用变体
dsh plugin --profile web add dshmarket                          # npm 包名
dsh plugin --profile web add @scope/package@version            # 指定版本
dsh plugin --profile web add https://github.com/.../v0.6.8.tar.gz  # GitHub tarball

# 装完后重启生效
dsh web
