# 学习记录 0001：DSH 课程的起点与关键定位

## 背景
用户已在「AI Agent 2.0」课程中从零手写过 Agent 循环、工具调用、记忆、Web 服务化。现在转向 DeepSeek Harness，目标是用「一切皆插件」的框架快速拼装出可扩展的个人 Agent。

## 关键洞察
1. **不要从「什么是 Agent」讲起**——用户已经懂 LLM + 工具 + 循环。直接从 Harness 层切入，建立「Agent = Model + Harness」的心智模型。

2. **DSH 的核心差异点是「一切皆插件」**——不仅模型和工具是插件，连 Agent 主循环、会话日志、沙箱都是可替换的。这是它和 Claude Code/Codex（精装房、封闭）以及 LangChain（抽象层厚）的本质区别。

3. **底层是 Cordis 微内核**——管插件的加载/卸载/依赖/热重载。写插件的本质就是写一个 `apply(ctx)` 函数，通过 `ctx` 注册能力。

4. **版本风险**：DSH 仍在 Developer Preview（0.1.2-rc.1），API 可能变动。教学中必须锁定版本号并标注风险。

5. **Node 版本硬门槛**：^22.19.0 或 >=24。用户当前 v22.18.0，需要升级——这是第一个实操障碍。
